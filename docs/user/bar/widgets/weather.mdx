Shows the current weather in the bar and opens the Weather control-center tab on click. Requires `[weather]` to be configured.

| Setting            | Type   | Default    | Description                                                                                       |
| ------------------ | ------ | ---------- | ------------------------------------------------------------------------------------------------- |
| `max_length`       | number | `160`      | Maximum length for the weather text                                                               |
| `show_condition`   | bool   | `true`     | Show condition text like `Overcast` next to temperature, or weather glyph                         |
| `show_temperature` | bool   | `true`     | Show temperature text like `38°C` next to weather glyph                                           |
| `glyph_position`   | string | `"before"` | Place the weather glyph `"before"` or `"after"` the text. See [Peek](/noctalia/bar/widgets/#peek) |
| `peek`             | bool   | `false`    | Show only the glyph and reveal the text on hover. See [Peek](/noctalia/bar/widgets/#peek)         |
| `peek_delay_ms`    | int    | `100`      | Hover time before the text reveals, from `0` to `2000` ms                                         |
| `format`           | string | `""`    | Template for the bar text, overriding `show_condition` and `show_temperature` (horizontal bars). See below. |

```toml
[widget.weather]
max_length       = 180
show_condition   = false
show_temperature = false
```


## Custom text

`format` builds the bar text from placeholders, for example a dew point readout for humid climates:

```toml
[widget.weather]
format = "{temp} / dew {dew}"
```

| Placeholder    | Value                                                            |
| -------------- | ---------------------------------------------------------------- |
| `{temp}`       | Current temperature, e.g. `72°F`                                 |
| `{feels}`      | Feels-like temperature                                           |
| `{high}` `{low}` | Today's high and low                                           |
| `{dew}`        | Dew point                                                        |
| `{humidity}`   | Relative humidity, e.g. `64%`                                    |
| `{wind}`       | Wind speed and compass direction, e.g. `8 mph NW`                |
| `{gust}`       | Wind gusts                                                       |
| `{pressure}`   | Sea-level pressure                                               |
| `{uv}`         | UV index                                                         |
| `{aqi}`        | US air quality index (needs `weather.air_quality`)               |
| `{cloud}`      | Cloud cover                                                      |
| `{visibility}` | Visibility                                                       |
| `{rain}`       | Today's chance of rain                                           |
| `{moon}`       | Moon phase name                                                  |
| `{condition}`  | Short condition text, e.g. `Overcast`                            |
| `{location}`   | Location name                                                    |

Unknown placeholders are left as written. The tooltip always lists the full set of current values: condition, temperature, feels like, high and low, dew point with a comfort label, humidity, wind and gusts, pressure, cloud cover, visibility, rain chance, UV and air quality.
